# Prompt-Based Long Descriptions

This folder contains long-description outputs generated directly from prompts. The exact prompt is included in the file prompt.txt

The `alt_text_descripcions_X-XX.md` files were produced from the corresponding `resum_estadistic_instanciesX-XX.json` versions, which were the result of the pipeline and were manually divided int files with 50 charts each. Then the md files were generated directly through prompting workflows in Chatgpt, Claude and Gemini LLM, rather than being derived from a separate post-processing pipeline.

The subfolders group the outputs by model or processing context.
